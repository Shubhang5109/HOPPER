Harmonized Ontology and Plant Pathology Exploration Repository (HOPPER) is a type of integrated plant disease knowledge database to address the current bottlenecks and gaps of existing databases. 
Hopper literally "Hops" between semantic layers of existing open-access databases to retrieve desired informatic serving as a exploration repository, instead of a database on its own.
Further functionality with more intelligent retrieval systems, curation of a personalized database, as well as an interactive user interface for live connectivity are yet to come.
Currently, rule-based and it is more of JARVIS than VISION.
